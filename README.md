# 🌤️ Python Hava Durumu Pro (CustomTkinter)

CustomTkinter kütüphanesi ve OpenWeatherMap API kullanılarak geliştirilmiş modern ve şık bir masaüstü hava durumu uygulaması.

## 🚀 Özellikler
- Anlık hava durumu, hissedilen sıcaklık, nem ve rüzgar hızı takibi
- Koyu (Dark) ve Açık (Light) tema desteği
- OpenWeatherMap API üzerinden canlı hava durumu ikonları
